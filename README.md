# St. Paul's Jesuit School (Belgaum) — Homepage UI

A responsive HTML + Tailwind CSS + vanilla JavaScript recreation of the homepage.

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
cd xaviers-homepage
python3 -m http.server 5500
```

Then visit http://localhost:5500 .

## Contents
- `index.html` — complete section markup, Tailwind utility classes, semantic structure
- `styles.css` — exact theme styling, section gradients, decorative textures, layout details, responsive rules
- `script.js` — functional hero carousel, mobile menu, search UI
- `assets/` — image crops extracted from the visual mockup so images are stored locally rather than depending on third-party image URLs
